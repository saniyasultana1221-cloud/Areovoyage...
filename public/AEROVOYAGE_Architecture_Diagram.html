Full-Stack System Architecture Work Diagram

1. End-to-End Workflow & Event Pipeline

1
300ms Debounce Search
User enters "Hyderabad" into GlassSearchBar. OpenStreetMap Nominatim API returns geocoded lat/lon.
2
60 FPS 3D Earth Spin
Math converts (lat, lon) to (x, y, z). Three.js tweens camera via shortest-path interpolation.
3
Atmospheric Re-entry Dive
After 1.1s alignment, hypersonic dive descends through clouds to open full Immersive City Experience.
4
Stripe & Supabase Checkout
Lead capture & Stripe test payment authorization. Persists to Supabase with reference ID receipt.

2. Frontend Architecture vs Backend Service Isolation

Frontend Presentation Layer
React 18 + Three.js
  • 🌐
    Spatial3DGlobe.tsx WebGL Earth sphere (R=80), NASA textures, atmosphere shaders, smooth 60 FPS lerp matrix.
  • 🔍
    GlassSearchBar.tsx 300ms debounced input, OpenStreetMap Nominatim geocoding, auto-rotate trigger.
  • 🚀
    AtmosphericDiveTransition.tsx & ImmersiveCityExperience.tsx Altitude re-entry countdown, full-screen city portal for Hyderabad/world cities.
  • 💳
    BookingModal.tsx & Lead Capture Guest form validation, dual-column Stripe sandbox card, booking confirmation receipt.
Backend Architecture & Data Layer
Supabase + REST APIs
  • 🗄️
    Supabase PostgreSQL Relational Schema Normalized tables: destinations, destination_details, reservations, reviews.
  • ⚡
    destinationService.ts & SWR Cache Asynchronous query engine with 5-minute in-memory SWR caching and local fallback repository.
  • 🔒
    stripeService.ts & supabaseService.ts Stripe test card authorization (4242 4242 4242 4242) and database record persistence.
  • 🌤️
    travelDataService.ts Open-Meteo real-time climate API and OpenStreetMap Nominatim geocoding.

3. Supabase Relational Database Schema

Table Name Primary Key Foreign Keys & JSONB Fields Description / Purpose
destinations city_slug (PK) city_name, country, lat, lon, daily_rate, rating Primary catalog of worldwide spatial destinations.
destination_details id (UUID PK) city_slug (FK), landmarks (JSONB), itinerary_days (JSONB) Rich relational data: Charminar, Golconda, day schedules, best times.
reservations id (AV-XXXX PK) user_email, full_name, dates, amount_paid, stripe_intent_id Confirmed guest booking records and lead capture persistence.
reviews id (UUID PK) city_id (FK), user_name, rating, comment, created_at Real-time user feedback with dynamic average rating recalculation.
